# Command reference

This chapter is the complete command and option reference for the `zeron` launcher.
The command line is parsed by `CliParser`, help is rendered by `CliHelp`, and this page is
generated from `CliMetadata`; run
`java -cp target/classes com.maruseron.zeron.DocumentationGenerator` from the repository
root after changing the metadata.

## Exit behavior

Successful commands exit with status 0. Invalid invocations, including unknown targets and
conflicting options, exit with status 64. A parse or resolution failure exits with status 65
or 71, and a compilation failure exits with status 70. With `--deny-warnings`, reported
warnings fail a successful stage with status 71.

## Commands

### `version`

```text
zeron version
```

Print the running Zeron distribution version.

The alias 'zeron --version' has the same behavior.

### `init`

```text
zeron init
```

Create a starter manifest and entry source.

Writes zeron.toml and src/main.zn in the current directory and refuses to overwrite either file.

### `build`

```text
zeron build [<target>] [options]
```

Compile the selected project target without launching it.

With no target name, selects [project].default-target, or the implicit project target described by [project].entry and [project].output.

### `run`

```text
zeron run [<target>] [options]
```

Compile and launch the selected project target.

Uses the same target resolution and warning policy as 'zeron build', then launches the generated main class from that target's output directory.

### `fmt`

```text
zeron fmt [--check] [<file-or-directory>...]
```

Format selected sources or the project's source roots.

With no paths, discovers .zn files under the source roots in ./zeron.toml.

### `lsp`

```text
zeron lsp [--manifest <file>] [--stdio]
```

Start the language server over stdio.

Does not take a target; analysis and formatting use the project-wide source set.

### `explain`

```text
zeron explain <ZR0000>
```

Print the bundled explanation for a diagnostic code.

### `dump`

```text
zeron dump <api-index|class-directory|library.jar>
       zeron dump --stdlib [package]
```

Print a public API index.

The optional --stdlib package filter accepts a dot-separated package name.

### `help`

```text
zeron help [command|option]
```

Show command and option help.

## Options

Options are accepted only by the commands listed for them. Unknown dash-prefixed arguments
are reported as options. `--deny-warnings` and `--no-deny-warnings` cannot be combined.

### `--manifest`

```text
--manifest <file>
```

Select the project manifest.

Defaults to zeron.toml in the current directory. Paths inside the manifest resolve relative to the manifest file.

Applies to: `build`, `lsp`, `run`.

### `--debug`

```text
--debug, -d
```

Print compiler traces.

Writes parser, resolver, and compiler traces to stderr. The short alias is -d.

Applies to: `build`, `lsp`, `run`.

### `--deny-warnings`

```text
--deny-warnings
```

Treat reported warnings as a failed build.

Reports warnings normally, then fails after the stage completes when any warning was produced. Overrides [build].deny-warnings and a target's deny-warnings setting.

Applies to: `build`, `run`.

### `--no-deny-warnings`

```text
--no-deny-warnings
```

Allow warnings without failing the build.

Overrides [build].deny-warnings and a target's deny-warnings setting. Cannot be combined with --deny-warnings.

Applies to: `build`, `run`.

### `--no-warnings`

```text
--no-warnings
```

Hide warning diagnostics.

Errors still print, and collected warnings still participate in --deny-warnings.

Applies to: `build`, `run`.

### `--root`

```text
--root <dir>
```

Add a standalone project source root.

Repeatable. Standalone project compilation requires both --root and --entry.

### `--entry`

```text
--entry <source.zn>
```

Select the standalone project entry source.

Resolved relative to the first --root.

### `--library`

```text
--library <path>
```

Add a Zeron library directory or JAR.

Repeatable. Project builds configure libraries in zeron.toml instead.

### `--java-classpath`

```text
--java-classpath <path>
```

Add a Java class directory or JAR.

Repeatable. Project builds configure Java roots in zeron.toml instead.

### `--stdlib`

```text
--stdlib <source|compiled>
```

Select the standard-library mode for direct compilation.

Project builds select this in [platform].stdlib instead. With 'zeron dump --stdlib', the same flag prints the bundled index; an optional package name filters its output.

### `--jar-output`

```text
--jar-output <file.jar>
```

Package compiler output as a Zeron library JAR.

Also accepted with --build-stdlib.

### `--build-stdlib`

```text
--build-stdlib <dir>
```

Compile the bundled standard library.

Writes a class directory and optionally packages it with --jar-output.

### `--stdio`

```text
--stdio
```

Use the default stdio transport.

Explicitly selects the transport used by language clients.

Applies to: `lsp`.

### `--check`

```text
--check
```

Report formatting differences without modifying files.

The command exits unsuccessfully when a selected file differs from canonical style.

Applies to: `fmt`.

## Target selection and precedence

`zeron build` and `zeron run` accept one optional positional target name. With no name, the
command selects `[project].default-target`; when no default target is configured, it selects
the implicit project target described by `[project].entry` and `[project].output`.

Effective settings resolve from built-in defaults, then `[project]` and `[build]`, then the
selected `[targets.<name>]` entry, then explicit command-line options. An unknown target is
an invalid invocation and reports the available target names.
