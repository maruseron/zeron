# Error code ZR1001: Unexpected character

The scanner encountered a character that is not part of Zeron's source syntax. Identifiers
must start with an ASCII letter or underscore, and may continue with ASCII letters, digits,
or underscores. Unicode text is allowed inside string literals and comments, but not in
identifiers.

```zeron
let 変数: Int = 5;
    ^^^^

fn bakeÉclair(): Unit = ...
       ^
```

Use ASCII characters in identifiers, or place the text in a string or comment.

```zeron
let variable: Int = 5;
let label = "café";
```

## Message covered

- Unexpected character: {character}
