# Error code ZR1002: Unterminated string literal

A string began with a double quote but the scanner reached the end of the source before finding its closing quote. Newlines are allowed in strings, but the closing quote is still required.

## Typical example

```zeron
let message = "hello;
```

## Suggested fix

Add the missing closing double quote.

```zeron
let message = "hello";

```

## Messages covered

- Unterminated string.
