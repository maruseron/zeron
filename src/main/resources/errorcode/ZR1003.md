# Error code ZR1003: Unterminated block comment

A block comment began with `/*` but reached the end of the source without a closing `*/`.
The scanner still returns the comment token with its source range so editor tooling can
highlight the incomplete comment.

## Typical example

```zeron
let value = 1; /* comment
```

## Suggested fix

Add the closing delimiter.

```zeron
let value = 1; /* comment */
```
