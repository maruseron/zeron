# Error code ZR1007: Invalid string escape

A string literal contains a backslash that does not start a supported escape sequence.

Supported escapes are `\\` (backslash), `\"` (double quote), `\'` (single quote), `\n` (line
feed), `\r` (carriage return), `\t` (tab), and a braced scalar escape such as `\u{1F600}`. A
backslash immediately before a line break is a line continuation, not an error; it removes the line
break from the value. A
braced escape must contain at least one hexadecimal digit and name a Unicode scalar value: at most
U+10FFFF and not a surrogate from U+D800 to U+DFFF.

```zeron
let bad = "line\ncolumn\q"; // error: \q is not an escape
let good = "line\ncolumn\t";
```

Write `\\` when the backslash itself is meant. Escape processing happens once, before the value
reaches the program, so a decoded `\n` is a real line feed inside the string, not two characters.
