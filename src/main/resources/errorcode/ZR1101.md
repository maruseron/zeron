# Error code ZR1101: Expected syntax

The parser reached a position where a specific token or syntactic construct is required, but the next input did not match. The exact expected token or construct is stated in the diagnostic message.

## Typical example

```zeron
fn greet(name: String {
    println(name);
}
```

## Suggested fix

Check the syntax immediately before the highlighted position. A missing delimiter or separator earlier in the construct can make the reported token appear unexpected.

```zeron
fn greet(name: String) {
    println(name);
}

```
