# Error code ZR1102: Invalid declaration

The source contains a declaration form that is not permitted in its current context or does not satisfy the declaration rules.

## Typical example

```zeron
public if (ready) { }
```

## Suggested fix

Check the declaration kind and its surrounding context; move it to an allowed location or use a supported declaration form.

```zeron
public fn start(): Unit { }

```

## Messages covered

- Bundled declarations cannot override their package.
- Star imports cannot have aliases.
