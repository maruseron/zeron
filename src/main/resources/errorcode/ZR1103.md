# Error code ZR1103: Invalid visibility

A visibility modifier is missing, unsupported, or applied to a declaration where it is not allowed.

## Typical example

```zeron
protected class Box {}
```

## Suggested fix

Use only the visibility modifiers supported for that declaration, and place them before the declaration.

```zeron
public class Box {}

```

## Messages covered

- Only values, functions, classes, and contracts may be public.
- Public top-level values must be immutable.
- Constructors must declare 'public' or 'private' visibility.
