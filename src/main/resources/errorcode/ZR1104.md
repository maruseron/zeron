# Error code ZR1104: Invalid external function declaration

An external JVM function declaration violates the source-level restrictions on where external declarations may appear or what signatures they may use.

## Typical example

```zeron
external fn size<T>(value: T): Int;
```

## Suggested fix

Keep external declarations at top level, give them an explicit return type, and use a supported non-generic signature.

```zeron
external fn size(value: String): Int;

```

## Messages covered

- External JVM functions are only allowed at top level.
- External JVM functions require an explicit return type.
