# Error code ZR1105: Invalid generic declaration

A generic declaration or type-parameter list does not meet the language rules. Generic functions need explicit return types, and type parameters and bounds are restricted by declaration kind.

## Typical example

```zeron
fn identity<T>(value: T) = value;
```

## Suggested fix

Declare the required type parameters and use generics only in supported positions.

```zeron
fn identity<T>(value: T): T = value;

```
