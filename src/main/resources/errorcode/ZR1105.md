# Error code ZR1105: Invalid generic declaration

A generic declaration or type-parameter list does not meet the language rules. Generic functions need explicit return types, and type parameters and bounds are restricted by declaration kind.

## Typical example

```zeron
fn identity<T>(value: T) = value;
```

## Suggested fix

Declare the required type parameters and use generics only in supported positions.

```zeron
fn identity<T>(value: T): T = value;

```

## Messages covered

- External JVM functions cannot be generic in this implementation.
- Generic functions require an explicit return type.
- Method type parameters cannot shadow enclosing type parameters.
- Type-parameter bounds are supported only on top-level generic functions.
- A generic declaration must declare a type parameter.
- Only nominal types can have type arguments.
