# Error code ZR1106: Too many parameters or arguments

A function declaration or call exceeds the JVM-compatible limit of 254 parameters or arguments.

## Typical example

```zeron
fn combine(a: Int, /* ... more than 254 parameters ... */): Int = a;
```

## Suggested fix

Split the operation into smaller functions or pass a value that groups related arguments.

```zeron
fn combine(input: Input): Int = input.left + input.right;

```

## Messages covered

- Can't have more than 254 parameters.
- Can't have more than 254 arguments.
