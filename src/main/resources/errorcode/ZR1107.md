# Error code ZR1107: Duplicate declaration component

The same declaration component appears more than once where only one occurrence is allowed, such as a type parameter or property accessor.

## Typical example

```zeron
fn pair<T, T>(left: T, right: T): T = left;
```

## Suggested fix

Remove or rename the duplicate component so each declaration element is unique.

```zeron
fn pair<T, U>(left: T, right: U): T = left;

```

## Messages covered

- Duplicate type parameter.
- Duplicate property getter.
- Duplicate property setter.
