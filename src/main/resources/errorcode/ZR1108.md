# Error code ZR1108: Invalid declaration structure

A class, contract, method, field, or constructor does not follow the required declaration structure.

## Typical example

```zeron
contract Box { 
    default property value: Int = ...;
}
```

## Suggested fix

Check the required order and form of members, constructors, and signatures for this declaration.

```zeron
contract Box {
    property value: Int;
}

```

## Messages covered

- A class can declare only one canonical constructor.
- Contract properties cannot have default implementations.
- Class and contract methods require an explicit return type.
- Only functions and named methods can be called.
