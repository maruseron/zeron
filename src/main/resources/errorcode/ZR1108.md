# Error code ZR1108: Invalid declaration structure

A class, contract, method, field, or constructor does not follow the required declaration structure.

## Typical example

```zeron
contract Box { 
    default property value: Int = ...;
}
```

## Suggested fix

Check the required order and form of members, constructors, and signatures for this declaration.

```zeron
contract Box {
    property value: Int;
}

```
