# Error code ZR1110: Invalid sealed contract declaration

A sealed modifier or permitted-class list is being used in a way that does not match the sealed-contract syntax.

## Typical example

```zeron
sealed class Shape {}
```

## Suggested fix

Use `sealed` only on a contract and provide a non-empty permitted-class list for sealed contracts.

```zeron
sealed contract Shape permits Circle { }

```

## Messages covered

- A sealed contract must declare at least one permitted class.
- Only sealed contracts may declare permitted classes.
- Only contracts can be sealed.
- Expect permitted class name.
- Expect '>' after permitted class type arguments.
