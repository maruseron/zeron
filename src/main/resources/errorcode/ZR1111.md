# Error code ZR1111: Invalid array type or literal

An array type or literal is missing its element type or required initial element, or uses an invalid number of type arguments.

## Typical example

```zeron
let values: Array<> = [];
```

## Suggested fix

Provide exactly one element type and at least one element in an array literal.

```zeron
let values: Array<Int> = [1];

```

## Messages covered

- Array expects one element type.
- Array requires an element type.
- Array literals must initialize at least one element.
