# Error code ZR1112: Control statement outside its context

A `break`, `continue`, or `return` statement appears where there is no enclosing loop or function that it can control.

## Typical example

```zeron
break;
```

## Suggested fix

Move the statement into the appropriate loop or function, or remove it.

```zeron
while (true) { break; }

```

## Messages covered

- Can only break inside of a loop.
- Can only continue inside of a loop.
- Can only return inside of a function.
