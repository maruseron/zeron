# Error code ZR1112: Control statement outside its context

A `break`, `continue`, or `return` statement appears where it cannot control execution. This
includes using these statements in a custom pattern body, where they could bypass required output
assignments.

## Typical example

```zeron
break;
```

## Suggested fix

Move the statement into the appropriate loop or function, or remove it.

```zeron
while (true) { break; }

```
