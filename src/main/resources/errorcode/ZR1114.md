# Error code ZR1114: Invalid match expression

The match expression is missing its required case structure or contains no cases.

## Typical example

```zeron
match (value) { }
```

## Suggested fix

Provide one or more match cases using the required pattern and arrow syntax.

```zeron
match (value) { 
    case Circle -> 1; 
    _ -> 0; 
}

```

## Messages covered

- A match expression must contain at least one case.
