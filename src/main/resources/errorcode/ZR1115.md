# Error code ZR1115: Invalid for expression operation

This diagnostic indicates that resolution encountered an unsupported operation while lowering a
for-expression. Ordinary source clauses use generators, local bindings, guards, and a final `yield`
or `collect` result clause.

## What to do

This is not a diagnostic for an unknown comprehension clause. If it is reported for valid
for-expression source, check that the generator types are supported by the current compiler and
report the smallest reproducing example.
