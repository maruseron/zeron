# Error code ZR1115: Invalid for expression operation

The operation in a for-expression pipeline is invalid or appears in an unsupported position.

## Typical example

```zeron
let result = for nums
    map x -> x * 2
    unknown
```

## Suggested fix

Use the supported stages in their required order: `map`, `flatMap`, `filter`, `drop`, `dropWhile`, `take`, `takeWhile`, and a terminal `collect` into a `Sink`.

```zeron
let result = for nums
    map x -> x * 2
    take 10
    collect
```
