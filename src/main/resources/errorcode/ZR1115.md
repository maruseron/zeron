# Error code ZR1114: Invalid for expression operation

The operation in a for expression is invalid.

## Typical example

```zeron
let result = for nums
    map x -> x * 2
    unknown
```

## Suggested fix

Only `map`, `filter` and `collect` operations are supported.

```zeron
let result = for nums
    map x -> x * 2
    collect
```

## Messages covered

- Unknown for expression operation.
