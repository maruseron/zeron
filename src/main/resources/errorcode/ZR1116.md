# Error code ZR1109: Invalid contract member declaration

A contract property or constructor is implemented by default, or a constructor is marked as mutating.

## Typical example

```zeron
contract Sink<T> {
    default property value = otherMethod();

    mut constructor of();

    otherMethod(): T;
}
```

## Suggested fix

Make the constructor or property declaration abstract, make sure constructors are not marked as mutating.

```zeron
contract Sink<T> {
    property value;

    constructor of();
}

```

## Messages covered

- Contract constructors cannot be marked mut.
- Contract constructors cannot have default implementations.
- Contract properties cannot have default implementations.
