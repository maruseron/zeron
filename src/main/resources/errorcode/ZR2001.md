# Error code ZR2001: Name not found

A referenced function, type, value, member, or protocol name could not be resolved in the current scope or through the available imports.

## Typical example

```zeron
fn answer(): Int = missingValue;
```

## Suggested fix

Check spelling and scope, declare the name, or add the appropriate import. For a member name, verify that the receiver?s type provides that member.

```zeron
let missingValue = 42;
fn answer(): Int = missingValue;

```

## Messages covered

- Unknown function '{name}'.
- Unknown contract.
- Unknown value '{name}'.
- Unknown symbol: '{name}'.
- Unknown property.
- Unknown field.
- Unknown named constructor.
- Unknown method: '{name}'.
- Unknown type '{name}'.
- Unknown generic type '{name}'.
