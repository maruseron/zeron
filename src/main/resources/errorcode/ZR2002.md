# Error code ZR2002: Duplicate or conflicting name

A name or declaration component conflicts with another declaration in the same relevant scope.

## Typical example

```zeron
let count = 1;
let count = 2;
```

## Suggested fix

Rename one declaration or remove the duplicate. If the conflict is between declaration kinds, choose distinct names.

```zeron
let firstCount = 1;
let secondCount = 2;

```

## Messages covered

- Top-level value '{name}' is already declared.
- Function '{name}' is already declared.
- Type name '{name}' is already declared.
- Duplicate contract method.
- Duplicate contract member.
- Duplicate class member.
- Duplicate contract conformance.
- A top-level function and value cannot share the name '{name}'.
