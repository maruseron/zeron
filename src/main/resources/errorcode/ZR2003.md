# Error code ZR2003: Invalid or conflicting import

An import target, imported package, or alias is invalid, unavailable, ambiguous, or conflicts with a name already visible in the package.

## Typical example

```zeron
import missing.package.Item;
```

## Suggested fix

Verify the target and package spelling. Resolve ambiguity with an explicit import or alias, and avoid aliases that shadow existing names.

```zeron
import library.geometry.Point as GeometryPoint;

```
