# Error code ZR2004: Inaccessible declaration

The requested declaration exists, but its visibility does not allow access from this location.

## Typical example

```zeron
class Box { 
    value: Int; 
}

fn read(box: Box): Int = box.value;
```

## Suggested fix

Use a public declaration, access it from an allowed scope, or change the declaration?s visibility if that is intended.

```zeron
class Box { 
    public value: Int; 
}

fn read(box: Box): Int = box.value;

```

## Messages covered

- Type '{name}' is not public.
- Property is private.
- Constructor is private.
- Named constructor is private.
- Method is private.
- Field is private.
