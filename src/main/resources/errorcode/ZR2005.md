# Error code ZR2005: Invalid generic use

A generic declaration, type, or call is used in a way that violates Zeron's supported generic rules. This includes unsupported generic positions, invalid bounds, and invalid generic function values.

## Typical example

```zeron
fn identity<T>(value: T): T = value;
let operation = identity;
```

## Suggested fix

Use generics only in supported declaration positions, provide valid type arguments and contract bounds, and keep polymorphic function values immutable.

```zeron
let operation = identity::<Int>;

```
