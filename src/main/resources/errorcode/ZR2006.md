# Error code ZR2006: Argument or parameter count mismatch

A call or type application supplies a different number of arguments than the target declaration requires.

## Typical example

```zeron
fn add(left: Int, right: Int): Int = left + right;
let total = add(1);
```

## Suggested fix

Compare the declaration?s parameter/type-parameter list with the call and supply the required number of arguments.

```zeron
let total = add(1, 2);

```
