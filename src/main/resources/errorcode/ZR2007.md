# Error code ZR2007: Invalid Java interop binding

An external Java binding is missing, malformed, or disagrees with the Java class-file metadata inspected by the compiler.

## Typical example

```zeron
external fn print(value: String): Unit;
```

## Suggested fix

Ensure the Java class is available on `--java-classpath`, the binding has a registered implementation, and its owner, method name, parameter types, and return type match the public JVM signature. Unsupported Java features receive a separate diagnostic.

```zeron
external fn print(value: String): Unit;

```
