# Error code ZR2008: Invalid sealed contract or match

A sealed contract implementation or match case violates the contract's permitted classes, type arguments, or exhaustiveness requirements.

## Typical example

```zeron
match (shape) { 
    case Circle -> 1; 
}
```

## Suggested fix

Ensure permitted classes conform as declared and make the match cover each permitted case, optionally using a final wildcard case.

```zeron
match (shape) { 
    case Circle -> 1; 
    case Square -> 2; 
}

```
