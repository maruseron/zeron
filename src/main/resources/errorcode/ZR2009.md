# Error code ZR2009: Invalid member access

A property, field, method, or constructor access is not valid for the receiver or operation being performed.

## Typical example

```zeron
class Box { }
fn read(box: Box): Int = box.value;
```

## Suggested fix

Verify the receiver type and member name, then use the member through the form it supports (instance, static, or constructor access).

```zeron
class Box { public value: Int; }
fn read(box: Box): Int = box.value;

```
