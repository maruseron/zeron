# Error code ZR2010: Invalid operator, cast, or type test

An operator, cast, assignment, or runtime type test is applied to operands or types that do not support that operation.

## Typical example

```zeron
let total: Int = 1 + "two";
```

## Suggested fix

Check the operand types and nullability, and choose an operation supported for those types.

```zeron
let total: String = "1" + "2";

```
