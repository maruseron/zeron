# Error code ZR2011: Invalid control flow or initialization flow

A control-flow construct is used outside its valid context, a required return path is missing, or an iteration protocol is not valid.

## Typical example

```zeron
fn value(): Int { 
    if (ready) { 
        return 1; 
    }
}
```

## Suggested fix

Place control statements in the appropriate loop/function and ensure every required normal path returns a value. For iteration, conform to the supported protocol.

```zeron
fn value(): Int { 
    if (ready) { 
        return 1; 
    } else { 
        return 0; 
    } 
}

```

## Messages covered

- Named constructor must return an instance on every normal path.
- Non-entry compilation-unit functions require an explicit return type.
- For loops require Array<T>, an integer range literal, or a type conforming to Iterable<T>.
- Missing iterator protocol contract '{name}'.
- Iterable.iterator() must return an Iterator<T> reference.
