# Error code ZR2012: Mutation is not permitted

The operation attempts to reassign an immutable binding or mutate a value through a read-only reference.

## Typical example

```zeron
let value = 1;
value = 2;
```

## Suggested fix

Declare the binding mutable when reassignment is intended, and use a mutable reference view for operations that change the referenced value.

```zeron
let mut value = 1;
value = 2;

```

## Messages covered

- Property assignment requires a mutable reference.
- Property compound assignment requires a mutable reference.
- Array slot assignment requires a mutable &Array<T> view.
- Cannot reassign immutable binding '{name}'.
- '??=' is currently supported only for mutable local bindings.
- Cannot capture mutable binding '{name}' in a lambda.
- Mutating method requires a mutable reference.
