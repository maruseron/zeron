# Error code ZR2013: Nullable value requires handling

A nullable value is used where a non-null value is required, or the type of a null value cannot be inferred safely.

## Typical example

```zeron
let value: Int? = null;
let next = value + 1;
```

## Suggested fix

Establish non-nullness with a supported check before use, or provide an explicit nullable type annotation where inference is insufficient.

```zeron
let value: Int? = null;
if (value != null) {
    let next = value + 1; 
}

```
