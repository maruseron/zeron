# Error code ZR2014: Type mismatch or failed inference

The actual type does not satisfy the type required by the surrounding expression or declaration, or the available constraints do not determine one consistent type.

## Typical example

```zeron
let value: Int = "text";
```

## Suggested fix

Compare the required and supplied types and adjust the expression, declaration annotation, or generic arguments so their types agree.

```zeron
let value: Int = 42;

```

## Messages covered

- Cannot infer type from declaration.
- Types are not exact.
- Expected {expected}, found {actual}.
- Conflicting type inferences for '{name}': {first} and {second}.
