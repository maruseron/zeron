# Error code ZR2015: Invalid declaration or program structure

A declaration or program relationship violates a semantic rule not covered by a more specific diagnostic family.

## Typical example

```zeron
let value: Int;
```

## Suggested fix

Review the diagnostic message and the declarations it refers to; make the declarations satisfy the stated language rule.

```zeron
let value: Int = 1;

```

## Messages covered

- Callee is not a function.
- Top-level values require an initializer.
- Can't read local variable in its own initializer.
- This type cannot be used as a runtime type-test target.
- The internal array operation requires an array value.
- Function reference does not resolve to a top-level function.
- Iterable contract must declare iterator().
