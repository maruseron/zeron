# Error code ZR2016: Top-level initialization cycle

Top-level values depend on one another in a cycle, so there is no valid order in which their initializers can run.

## Typical example

```zeron
let first: Int = second;
let second: Int = first;
```

## Suggested fix

Break the cycle by removing or deferring at least one dependency in the reported chain.

```zeron
let first: Int = 1;
let second: Int = first + 1;

```
