# Error code ZR2017: Invalid initializer

An initializer reads a value before it is available or uses an expression form that is not
supported for field initialization. Field initializers may read only earlier fields and support
only literals, operators, and those earlier-field reads.

## Typical example

```zeron
class Pair {
    first: Int = second;
    second: Int = 2;
}
```

## Suggested fix

Initialize fields in dependency order, and avoid reading a local variable from its own initializer.

```zeron
class Pair {
    second: Int = 2;
    first: Int = second;
}
```
