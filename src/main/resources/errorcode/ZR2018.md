# Error code ZR2018: Invalid pattern output assignment

Every output declared by a custom pattern must be assigned exactly once on every path that
completes normally.

## Typical example

```zeron
class Box {
    public pattern split(left: Int) {
        if (true) { left = 1; }
    }
}
```

## Suggested fix

Assign each output exactly once on all completing paths.

```zeron
class Box {
    public pattern split(left: Int) {
        if (true) { left = 1; } else { left = 0; }
    }
}
```
