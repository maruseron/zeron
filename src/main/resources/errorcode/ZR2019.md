# Error code ZR2019: Named constructor does not return an instance

A named constructor must produce an instance on every normal path. A path that raises an effect
does not need to return normally.

## Typical example

```zeron
class User {
    public constructor create(valid: Boolean) {
        if (valid) { return this; }
    }
}
```

## Suggested fix

Ensure every path that completes normally returns the constructed instance.

```zeron
class User {
    public constructor create(valid: Boolean) {
        if (valid) { return this; } else { return this; }
    }
}
```
