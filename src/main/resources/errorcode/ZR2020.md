# Error code ZR2020: Invalid iteration source

A `for` loop or for-expression source must be an array, an integer range, or a value that conforms
to `Iterable<T>`.

## Typical example

```zeron
for (let item in 42) { }
```

## Suggested fix

Iterate over an array, range, or an `Iterable<T>` value.

```zeron
for (let item in 1..5) { }
```
