# Error code ZR2021: Invalid collection sink

A for-expression ending in `collect` requires a sink that conforms to `Sink<T>` for the element
type being collected.

## Typical example

```zeron
let values = for [1, 2, 3]
    collect 0;
```

## Suggested fix

Use a mutable sink whose `add` operation accepts the collected element type.

```zeron
import zeron.collections.List;
let values = for [1, 2, 3]
    collect List<Int>.empty();
```
