# Error code ZR2021: Invalid collection sink

A for-expression ending in `collect` requires a mutable sink that conforms to `Sink<T>` for the
projected element type.

## Typical example

```zeron
let values = for item in [1, 2, 3]
    collect item into 0;
```

## Suggested fix

Use a mutable sink whose `add` operation accepts the collected element type.

```zeron
import zeron.collections.List;
let values = for item in [1, 2, 3]
    collect item into List<Int>.empty();
```
