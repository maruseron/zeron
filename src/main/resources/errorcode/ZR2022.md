# Error code ZR2022: Generic type inference failed

The compiler could not determine a generic type argument from the call, function value, or
polymorphic lambda's available context, or different inputs inferred incompatible types.

## Typical example

```zeron
fn empty<T>(): Array<T> = [];
let values = empty();
```

## Suggested fix

Supply explicit type arguments or add enough type context for the generic parameters to be
inferred consistently.

```zeron
let values = empty<Int>();
```
