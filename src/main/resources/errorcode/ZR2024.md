# Error code ZR2024: Unsupported Java interop feature

The Java API or operation uses a feature outside the subset currently supported by Zeron's Java
interop.

## Typical example

```zeron
external fn parse<T>(value: T): T;
```

## Suggested fix

Use a supported Java signature and interop operation. The current subset does not support Java
generics, fields with unsupported descriptors, inherited members, general SAM conversion, or
unsupported Java array signatures. Consult the Java interop guide for the current supported
surface.
