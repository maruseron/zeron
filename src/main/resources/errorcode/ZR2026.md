# Error code ZR2026: Hashable.hash must return Long

`Hashable.hash` returns a 64-bit `Long` in this release. A witness implementation written for the
former 32-bit contract returns `Int` and must be updated.

## Typical example

```zeron
import zeron.lang.Hashable;

witness Hashable<User> for User {
    fn hash(): Int = 0;
}
```

## Suggested fix

Change the return type to `Long` and return a 64-bit value consistent with equality.

```zeron
import zeron.lang.Hashable;

witness Hashable<User> for User {
    fn hash(): Long = 0L;
}
```
