# Error code ZR2028: Intrinsic helper declared outside the standard library

A small set of standard-library functions, including `allocateArray`, `clearArraySlot`,
`allocateByteArray`, and `unwrapSome`, are compiler intrinsics. The compiler recognizes those
declarations by their qualified standard-library name. A function with an identical name and body
in any other package is an ordinary function, so its only statement calls itself forever.

## Typical example

```zeron
fn allocateArray<T admits nullable + mutable>(size: Int): &Array<T> = allocateArray<T>(size);
```

## Suggested fix

Use the public allocation entry point. `generateArray` fills every slot through an initializer, so
the result never exposes uninitialized storage.

```zeron
import zeron.internal.generateArray;

fn emptySlots<T admits nullable + mutable>(size: Int): &Array<T?> =
    generateArray<T?>(size, _ -> null);
```

Prefer a standard collection type such as `ArrayList<T>` when the program needs a growable
sequence. Raw length-based allocation stays internal to the standard library.
