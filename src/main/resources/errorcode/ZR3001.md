# Error code ZR3001: Generated program name conflicts with a declared type

A source class or contract has the same name as the generated program class, so both cannot be emitted under that name.

## Typical example

```zeron
class Main {}
```

## Suggested fix

Rename the source type or choose a different entry-file/program class name.

```zeron
class MainModel {}

```

## Messages covered

- Contract name conflicts with generated program class: {name}
- Class name conflicts with generated program class: {name}
