# Error code ZR3010: Anonymous witness declarations are deprecated

An anonymous witness has no source name, so it cannot be exported, imported, or named in a
diagnostic. Give the witness a name; the declaration keeps working during the migration release.

## Typical example

```zeron
witness<T: Display> Display for Buffer<T> {
    fn toString(): String = render(this);
}
```

## Suggested fix

```zeron
public witness BufferDisplay<T: Display>: Display for Buffer<T> {
    fn toString(): String = render(this);
}
```
