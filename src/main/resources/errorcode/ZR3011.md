# Error code ZR3011: Unused local variable

A local binding is declared but never referenced. Remove it or use it; prefix a deliberately unused
binding with an underscore.

## Typical example

```zeron
fn render(value: Int) {
    let unused = value * 2;
    println(value);
}
```

## Suggested fix

```zeron
fn render(value: Int) {
    println(value);
}
```
