# Error code ZR3015: Unnecessary mutable projection

A parameter requires a mutable reference (`&T`) but the body only reads through it. Narrow the
parameter to a read-only `T` so callers do not need to provide mutable access.

## Typical example

```zeron
fn size(values: &ArrayList<Int>): Int = values.size();
```

## Suggested fix

```zeron
fn size(values: ArrayList<Int>): Int = values.size();
```
