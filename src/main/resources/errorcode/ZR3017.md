# Error code ZR3017: Local declaration shadows an outer declaration

A local binding or parameter reuses a name that is already visible from an enclosing scope. Rename
one of them so readers do not have to track which binding is in effect.

Implicit `this` receivers are compiler-generated and cannot be renamed, so nesting object literals
does not report this warning for their receivers.

## Typical example

```zeron
fn render(value: Int) {
    let value = value + 1;
    println(value);
}
```

## Suggested fix

```zeron
fn render(value: Int) {
    let adjusted = value + 1;
    println(adjusted);
}
```
