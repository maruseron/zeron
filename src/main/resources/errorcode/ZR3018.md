# Error code ZR3018: Nullable return type

A public function, or a public method on a public class, returns `T?`, which makes every caller
handle a possible `null`. When `null` is not meaningful to callers, return `Option<T>` for an
optional value or `Result<T, _>` when the absence carries a failure reason.

Package-private classes and private methods may use a nullable return to keep an internal
representation simple; this warning reports only the externally visible API.

## Typical example

```zeron
public fn findName(id: Int): String? = ...;
```

## Suggested fix

```zeron
public fn findName(id: Int): Option<String> = ...;
```
