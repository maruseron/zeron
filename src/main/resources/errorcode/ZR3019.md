# Error code ZR3019: Direct Task.value() bypasses the Await policy

`Task.value()` joins the task directly. It does not perform `Await`, so an enclosing handler cannot
choose the waiting policy, and a join that happens during scope shutdown can deadlock. When the
task's effect row is empty, `await(task)` is the async-facing spelling: it performs `Await` first and
then reads the finished value.

This warning reports only the case where the effect row is concretely empty. A task with a non-empty
row still re-raises its effects from `value()`, and the caller's row decides whether that is
accepted.

## Typical example

```zeron
let task = spawn(scope, () -> 42);
return task.value();
```

## Suggested fix

```zeron
let task = spawn(scope, () -> 42);
return await(task);
```
