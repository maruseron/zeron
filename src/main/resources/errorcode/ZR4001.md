# Error code ZR4001: Package does not match source directory

In project compilation, a source file's declared package must match its directory relative to the configured source root.

## Typical example

```text
src/app/Util.zn  (declares package tools)
```

## Suggested fix

Move the source file to the package-matching directory or update its package declaration.

```text
src/tools/Util.zn  (declares package tools)
```

## Messages covered

- Package '{packageName}' in {sourcePath} must match its directory under source root '{sourceRoot}' (expected '{expectedPackage}').
